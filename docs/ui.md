# 정글5 (jungle5) UI 설계

- **문서 상태:** Review v0.4 / 시안 승인, 전 절 작성. PRD D-22(글 구분 제거) 반영
- **근거 문서:** [PRD](prd.md) v1.0, [TSD](tsd.md) v0.5
- **현재 구현:** M1 화면은 기능 확인용 기본 UI로 운영 중이다. 이 문서의 결정은 M1 화면에 먼저 적용하고, M2 화면은 처음부터 이 문서를 따른다.
- **작성 방식:** 인터뷰로 UI 결정(UD-xx)을 하나씩 확정하고 각 절을 채운다.

## 1. 디자인 방향

**차분한 문서형.** Notion·위키처럼 흰 배경과 글을 중심에 둔다. 카드 대신 구분선과 넓은 여백을 쓴다. 이 사이트의 목적은 "오래 읽고 다시 찾는 지식 축적"(PRD 1절)이므로, 장식보다 읽기와 훑어보기를 우선한다.

- **색:** 크래프톤 정글 공식 사이트(jungle.krafton.com)의 `jungle` 팔레트를 참고한다. 진한 그린을 버튼에, 시그니처 민트를 포인트에만 쓴다.
- **상표:** 크래프톤·정글의 공식 로고와 상표는 쓰지 않는다. 공식 사이트로 오해받지 않도록 로고는 자체 워드마크로 만든다.
- **기기:** 데스크톱을 우선으로 설계한다. 글 작성과 모임 기록은 PC에서 하고, 모바일은 읽기와 댓글 중심으로 지원한다.

| UD-14 | 카테고리 탭 | 지식 화면 위쪽 탭: "전체 (N)" 고정 첫 칸 + 글 수 많은 순 6개(각 글 수 표시) + "더 보기 N ▾"(검색 가능한 목록, 같은 순서). 선택한 카테고리는 항상 탭 줄에 보이게 하고, 6개 밖이면 6번째 자리에 잠시 넣는다. 글 수가 같으면 이름순 | 사용자 결정. 티스토리의 "전체보기 + 글 수"를 참고. 순서가 자주 바뀌지 않도록 최근 활동이 아닌 전체 글 수를 기준으로 한다 |
| UD-15 | 스터디 참여 | 참여·나가기 버튼이 없다. 비멤버 스터디 행에는 "참여 방법" 버튼이 있고, 누르면 스터디의 참여 안내(예: Discord 채널 링크)를 펼친다. 내 정보와 스터디 화면에 "Discord 역할 새로고침" 버튼을 둔다 | PRD D-23 (멤버십 = Discord 역할) |

### 3.2 의미 토큰

색은 아래 의미 토큰으로만 쓴다. 컴포넌트에 색 값을 직접 쓰지 않는다. 괄호 안은 해당 배경에 대한 대비다.

| 토큰 | 라이트 | 다크 | 용도 |
|---|---|---|---|
| `bg` | #FFFFFF | #0E1A1F | 페이지 배경 |
| `surface` | #F7F8F9 | #13252C | 입력칸, 코드 블록, 사이드바 |
| `border` | #E5E7EB | #22363E | 구분선, 테두리 |
| `text` | #111827 (17.7) | #E6EDEF (14.9) | 본문 |
| `text-muted` | #6B7280 (4.8) | #94A3AB (6.8) | 메타 정보 |
| `primary` | #037D4E, 흰 글자 (5.2) | #05D182, #09323D 글자 (6.8) | 주 버튼 |
| `primary-hover` | #025334 | #33D7A7 | |
| `link` | #037D4E (5.2) | #33D7A7 (9.6) | 링크 |
| `accent` | #05D182 | #05D182 | 로고 점, 현재 메뉴 밑줄, 포커스 링. 글자에는 쓰지 않는다 |
| `accent-subtle` | #E6FAF4 (위 그린 글자 4.8) | #12352F | 태그, 선택된 필터 배경 |
| `danger` | #B42318 (6.6) | #F97066 (6.4) | 삭제, 오류 |

모든 글자와 배경 조합은 WCAG AA(4.5:1) 이상이다. 다크 모드에서는 민트를 주 버튼에 쓸 수 있다. 어두운 배경에서는 민트의 대비가 충분하기 때문이다.

### 3.3 서체·간격

- **서체:** `Pretendard Variable`, 대체 서체는 시스템 산세리프. 코드는 시스템 모노스페이스.
- **본문:** 16px / 줄 간격 1.7. 글 상세 본문의 최대 폭은 약 72자(`max-w-prose`)로 둔다.
- **간격:** 4px 단위. 섹션 사이 40px, 목록 행 위아래 12~18px, 본문 영역 좌우 32px(모바일 16px).
- **모서리:** 버튼·입력칸 8px, 작은 배지 4px, 아바타 원형.
- **그림자:** 쓰지 않는다. 구분은 `border`로 한다. 예외는 모바일의 떠 있는 글쓰기 버튼 하나다.
- **제목 크기:** 페이지 제목 26px/700, 섹션 제목 18px/700, 목록 제목 17px/600, 메타 13px `text-muted`.

## 4. 레이아웃·내비게이션

### 4.1 데스크톱 (1024px 이상)

```text
┌──────────────┬─────────────────────────────────────────┐
│ 정글●5       │ [검색 (/)]                     ☾  (아바타) │
│              ├─────────────────────────────────────────┤
│ 홈           │                                         │
│ 지식         │   본문 영역 (최대 폭 768px, 가운데)         │
│ 스터디       │                                         │
│   ● DDIA     │   지식 화면 위쪽:                         │
│   ● CKAD     │   전체 86 | 프론트엔드 23 | … | 더 보기 8 ▾ │
│              │                                         │
│              │                                         │
│ [+ 글쓰기]    │                                         │
└──────────────┴─────────────────────────────────────────┘
```

- **사이드바 (UD-13):** 폭 240px, `surface` 배경, 화면에 고정. 현재 메뉴는 `accent` 막대(왼쪽 3px)로 표시한다.
  - 메뉴는 홈 / 지식 / 스터디 세 개다. "스터디" 아래에 내 스터디(Discord 역할 기준, 진행 중인 것만)를 바로가기로 붙인다. 참여한 스터디가 없으면 아무것도 붙이지 않는다.
  - 카테고리는 사이드바에 두지 않는다. 지식 화면의 탭(UD-14)으로 고른다.
  - 맨 아래에 주 버튼 "글쓰기"를 둔다. 운영자에게는 아바타 메뉴에 "카테고리 관리"를 둔다.
- **상단 바:** 검색창(`/` 키로 포커스, 지식 목록으로 이동), 다크 모드 토글, 아바타 메뉴(내 정보, 카테고리 관리(운영자), 로그아웃).

### 4.2 모바일 (1024px 미만)

- 상단 바: 메뉴 버튼(☰), 워드마크, 검색 아이콘, 아바타.
- 메뉴 버튼은 사이드바와 같은 내용을 왼쪽 서랍으로 연다. ESC와 바깥 클릭으로 닫고, 열려 있는 동안 포커스를 서랍 안에 가둔다.
- 글쓰기는 오른쪽 아래 떠 있는 버튼으로 제공한다.

## 5. 화면 구성

시안(UD-12)을 기준으로 한다. 시안에 없는 화면은 같은 규칙으로 만든다.

| 화면 | 경로 | 구성 |
|---|---|---|
| 홈 | `/` | "이번 주" 제목 + 주간 날짜 → 모임 목록(왼쪽에 요일·시각, 오른쪽에 스터디·회차·장소 / 범위 / 연결 글 수) → 최근 지식 5개 + "전체 보기" |
| 지식 목록 | `/posts` | 제목 + 결과 요약("프론트엔드 · '훅' 검색 결과 3건") → 선택된 필터 칩(카테고리, 태그, 해제 버튼) + "+ 태그" → 목록 → "더 보기". 검색어는 상단 바 검색창에서 입력 |
| 글 상세 | `/posts/:id` | 메타(카테고리·작성자·시각, 연결된 회차 링크) → 제목 → 본문(최대 72자 폭) → 태그·참고 링크 → 작성자 동작(수정·삭제) → 댓글 |
| 글 작성·수정 | `/posts/new`, `/posts/:id/edit` | 제목(큰 입력칸, 테두리 없음) → 카테고리·태그·회차 연결 한 줄 → 본문 작성/미리보기 탭 → 참고 링크 → 하단 고정 바(임시저장 상태, 취소, 등록) |
| 스터디 목록 (M2) | `/studies` | 제목 + "스터디 만들기"(운영자만) → 내 스터디(이름, 목표, 멤버 수·진행 회차, 오른쪽에 다음 모임) → 참여할 수 있는 스터디("참여 방법" 펼침) → "종료된 스터디 N개 보기" |
| 스터디 상세 (M2) | `/studies/:id` | 이름·목표 (비멤버면 참여 안내) → 다음 모임 → 회차 목록(번호, 제목, 일시, 상태) → 공통 자료 → 멤버(Discord 역할 기준) |
| 회차 상세 (M2) | `/rounds/:id` | 2단: 왼쪽(회차 제목·목표 → 연결된 글 + "이 회차에 글 쓰기" → 모임 기록), 오른쪽 정보 칸(모임 일시·장소, 학습 기간, 지난 회차에서 넘어온 것, 마지막 수정자, 편집 링크). 1024px 미만에서는 정보 칸이 제목 아래로 내려온다 |
| 내 정보 | `/me` | 프로필 + 내 스터디 역할 + "Discord 역할 새로고침" → 테마 설정(시스템/라이트/다크) → 로그아웃 → 탈퇴(위험 영역, `danger` 테두리) |
| 카테고리 관리 | `/admin/categories` | 표 형태: 이름, 글 수, 상태, 이름 변경·보관 |

## 6. 컴포넌트

| 컴포넌트 | 규칙 |
|---|---|
| `Button` | primary(`primary` 배경), secondary(`border` 테두리), danger(`danger` 글자·테두리), ghost(아이콘 버튼). 높이 40px, 모바일 터치 영역 44px 이상. 진행 중에는 비활성화하고 문구를 "저장 중…"으로 바꾼다 |
| `ListRow` | 구분선 목록의 한 행. 전체가 링크다. 제목(17/600) + 미리보기(선택, 2줄 말줄임) + 메타(13px muted). 마우스를 올리면 제목에 밑줄 |
| `FilterChip` | `accent-subtle` 배경 + 해제 버튼(aria-label 필수) |
| `Sidebar`, `MobileDrawer` | 4.1~4.2절. 같은 데이터를 쓴다 |
| `ThemeToggle` | 시스템 → 라이트 → 다크 순환. `localStorage['jungle5:theme']`에 저장하고, 실패하면 시스템 설정을 쓴다 |
| `Markdown` | 기존 렌더러를 유지하고 스타일만 바꾼다. 코드 블록은 `surface` 배경, 표·인용은 `border` |
| `ConfirmDialog` | 삭제·탈퇴처럼 되돌릴 수 없는 동작에 쓴다. 확인 버튼은 danger, 기본 포커스는 취소 |
| `EmptyState` | 점선 테두리 상자 + 한 줄 안내 + 다음 행동 링크 (예: "첫 글을 써 보세요") |
| `Avatar` | Discord 아바타, 실패 시 이름 첫 글자(`accent-subtle` 배경). 탈퇴한 멤버는 회색 원 |

## 7. 인터랙션·상태

- **로딩:** 목록은 실제 행 높이의 회색 막대(스켈레톤) 3개를 보여 줘 레이아웃이 밀리지 않게 한다. 버튼은 비활성화 + 문구 변경.
- **빈 상태:** EmptyState. 오류와 빈 상태를 다른 문구로 구분한다.
- **오류:** 화면 상단 알림 상자(`danger`)에 무엇이 실패했는지와 "다시 시도" 버튼을 둔다. 입력 오류는 해당 칸 아래에 표시한다.
- **동시 편집 충돌 (M2):** "다른 멤버가 먼저 저장했습니다" 알림과 함께 왼쪽에 최신본, 오른쪽에 내 입력을 나란히 보여 준다. 내 입력은 지우지 않는다 (TSD 8.2).
- **임시저장:** 글쓰기 하단 바에 "임시저장됨 · 방금"을 muted로 표시한다.
- **성공 알림:** 저장·삭제 후 화면 아래쪽에 3초짜리 알림(토스트)을 띄우고, 스크린리더에도 읽힌다(`aria-live="polite"`).

## 8. 접근성·반응형

- **대비:** 모든 글자는 4.5:1 이상 (3.2절).
- **상태 표현:** 상태를 색으로만 나타내지 않고 글자를 함께 쓴다.
- **포커스:** 키보드 포커스는 `accent` 2px 외곽선으로 항상 보이게 한다.
- **키보드:** 모든 동작을 키보드로 할 수 있다. 단축키는 `/`(검색) 하나만 둔다.
- **반응형 기준점:** 1024px (사이드바 ↔ 서랍), 640px (회차 상세 2단 → 1단, 필터 줄바꿈).
- **모바일:** 가로 스크롤 없음. 본문 표와 코드 블록은 자기 상자 안에서만 가로 스크롤한다.
- **움직임:** `prefers-reduced-motion`이면 서랍·토스트 애니메이션을 끈다.
